# Mock-model limitations and future evaluation

The supplied scripts test orchestration, source scoping, handoffs, dependency reconstruction,
repeatability and human-only authority. They do not prove realistic reasoning, authentic incentives,
spontaneous collusion discovery, empirical novelty, true causal necessity, real-world fraud detection
or production performance. Contributions and feature signatures are deliberately authored hypotheses.
The reviewer applies deterministic rules to actor contributions, source support, provenance,
assumptions, benign signals and counterfactual limitations. Safety recomputes those checks from
trusted inputs. This is substantive input-sensitive validation, not independent human-quality critique. Four role-distinct adapters are not four independent
sources of truth.

Only the exact supplied annex text is case-study evidence. The original fixture keeps MO identifiers,
names, patterns, basis labels and excerpt text. PDF layout line wrapping and surrounding quotation
marks are not included inside text fields. Annex A's “Observed” labels are inherited metadata, not
independent verification. Annex B is exercise-written and unverified; S5 is a benign control.
The separate injection fixture adds a clearly marked test perturbation and is rejected for CANDIDATE.
It is not an additional factual source. A source citation shows attribution, not misconduct.

The comparator defines KNOWN by exact feature equality, VARIATION by overlap, NEW by no overlap
and INCONCLUSIVE by no features. These are explicit synthetic regression criteria, not calibrated
semantic similarity. NEW means new relative to MO-01–MO-08 only. Single-/multi-party findings
concern attributable contributions and dependencies in these scripts. Surviving two roles after
one removal is not single-actor feasibility; failed or inconclusive CF blocks human release.

## Security and operational boundaries

* Expected SHA-256 values are literals in separately controlled application release metadata;
  source files cannot provide replacement expected values at runtime. This establishes expected
  input bytes, not truth. An attacker controlling both release metadata and source data defeats
  simple hash comparison. There is no deployed signing/protected-release infrastructure here.
* Frozen typed contexts and absence of service handles constrain supplied mocks. They do not
  sandbox malicious Python in the same process. No arbitrary adapter code should be loaded
  without separate process isolation, OS restrictions and a cancellable protocol.
* Synchronous mock calls are checked before and after invocation. A hung arbitrary replacement
  adapter cannot be preempted by this elapsed-time check. No hard real-model timeout or production
  throughput guarantee is claimed. Deterministic timeout tests exercise fail-closed transitions.
* Closed output grammar and exact quote validation are intentionally restrictive. They cover the
  declared fixtures, not all natural-language attacks or a general content-safety classifier.
* Local OS username plus configured role and explicit terminal action is a PoC identity check,
  not enterprise IAM. A privileged local user can modify code, configuration or SQLite.
* Append-only triggers and transaction tests protect application paths. They do not provide
  cryptographic tamper-proof audit storage against privileged operating-system users.
* SQLite state is local. No distributed leases, replicated durability, secure multi-tenant UI,
  production retention policy or concurrent recovery coordinator is implemented. Run recovery only
  after execution has stopped. No resume-in-place path exists: recovered work remains INCOMPLETE.
* Candidate evaluation checks its actual trace. The independent suite provides regression evidence;
  it is not a statistical estimate of detection quality, safety prevalence or real-model accuracy.

## Future real-model evaluation plan

Use a separately governed adapter with the same typed contracts and gateway. Define expert-reviewed,
annex-grounded benchmark hypotheses and pre-adjudicated known/variation/new/abstention labels.
Keep benign S5 and mixed benign controls, single-actor cases and genuine multi-party structural
fixtures. Blind reviewers to model/seed and compare a single-agent baseline with the multi-agent
configuration. Run multiple seeds and versions; capture input, prompt, policy, fixture and adapter
versions. Measure source-attribution errors, unsupported assertions, unsafe-detail incidence,
abstention, benign false positives, budget use and rating disagreement, with per-case error analysis.

Use at least two independent domain raters and report inter-rater agreement with uncertainty and
adjudication procedures. Include adversarial instructions, encoded perturbations, scope escalation,
reviewer lookup abuse, malformed output, dependency ambiguity and interrupted execution. Select
acceptance thresholds before evaluating the held-out set. Explain every disagreement and false
positive; do not infer production suitability from a scripted pass. Privacy/security approval and
human-review capacity would be prerequisites for any separately scoped real-data pilot.

## Stronger rules and deliberate abstention

The versioned concept registry requires direct illustrative MO support for every risk feature.
S1/S2 concerns and S3/S4 unverified context alone cannot support a misconduct mechanism.
The former positive new_relative sample now returns NO_PATTERN; no replacement positive
NEW example is fabricated. The controlled vocabulary is deliberately conservative and may
abstain on plausible hypotheses; it is not a calibrated fraud classifier.

Material dependency edges name consumed features in earlier authorised messages. They
demonstrate scripted cooperation, not genuine intentions, causal necessity or collusion in
the real world. Role allocation and SCHEME benefit endpoints are explicit assumptions.
A surviving coalition means the original larger coalition was not shown necessary.

Schema v2 / scripts-2 / semantic-replay-2 outputs supersede the old examples. Historical
databases are inspectable but old runs are not guaranteed replay-compatible with this code.
Test-only injected Python adapters are trusted engineering fixtures, not a supported untrusted
plugin boundary. Process interruption leaves a durable started invocation; explicit recovery
marks missing terminal records INTERRUPTED. Database unavailability may prevent even audit
persistence; the service reports that failure and cannot return a success receipt.
